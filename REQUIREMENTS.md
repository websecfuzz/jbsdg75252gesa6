# Requirements

## Hardware Requirements
- Commodity PC or Server with at least 8GB of RAM and 4 CPU cores.
- Minimum 50GB of free disk space for Docker images, logs, and fuzzing data.
- Internet connection for pulling Docker images and dependencies.

## Software Requirements
- **Operating System:** Linux (Ubuntu 20.04/22.04 or similar distributions are recommended).
- **Docker:** Installed and running (Docker Engine 20.10+ and Docker Compose v2+).
- **Python:** Python 3.8 or higher.
- **Python Dependencies:** Provided in `requirement.txt`.

## Environment Setup
Any deviation from a standard Linux environment using Docker and Python 3 may require manual adjustments to the helper scripts in the `/scripts` directory.
